# BossBarVanish

This Minecraft Plugin serves as an indicator to the player whether the player is in vanish or not.
It is an addition to other plugins that do not have this feature.

## Supported Plugins
- [PremiumVanish](https://www.spigotmc.org/resources/premiumvanish-stay-hidden-bungee-support.14404/)
- [SuperVanish](https://www.spigotmc.org/resources/supervanish-be-invisible.1331/)
- [VelocityVanish](https://modrinth.com/plugin/sayanvanish)
- [AdvancedVanish](https://www.spigotmc.org/resources/advancedvanish.86036/)
- [SimpleVanish](https://www.spigotmc.org/resources/simplevanish-1-13-2-1-20.107529/)
- [SayanVanish](https://modrinth.com/plugin/sayanvanish)
